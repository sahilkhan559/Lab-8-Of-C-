# Lab 8 – Structures in C++

## Software Construction and Development

This repository contains Lab 8 practical tasks focused on **Structures in C++**. It demonstrates how to define structures, store related data members, access structure members, and perform calculations using structures.

## Objectives

- Understand structures in C++.
- Learn how to group related data using a single structure.
- Understand structure variables and the dot (`.`) operator.
- Perform calculations and comparisons using structures.

## Tasks Performed

### Task 1 – Student Structure
- Create a Student structure.
- Store student name, roll number, and GPA.
- Input and display student information.

### Task 2 – Laptop Structure
- Create a Laptop structure.
- Store laptop brand, RAM, and price.
- Display laptop specifications.

### Task 3 – Rectangle Structure
- Create a Rectangle structure.
- Input length and width.
- Calculate and display area and perimeter.

### Task 4 – GPA Comparison
- Input data for two students.
- Compare their GPA values.
- Display the student with higher GPA.
- Display a message if both students have equal GPA.
